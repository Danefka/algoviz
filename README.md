# Algo Lab 0.6.0

Минималистичное десктопное приложение для пошагового просмотра алгоритмов.
Живую анимацию рисует Qt; Manim нужен только для экспорта MP4.

В меню доступны «сортировки» → пузырьковая сортировка и сортировка слиянием.
В 0.6.0 подготовлена общая визуализация для будущего Quick Sort; сам алгоритм пока не добавлен.

## Запуск

Распакуй архив в новую папку и открой терминал рядом с main.py.
Закрой предыдущую версию приложения.

~~~bash
uv run python main.py
~~~

Первый запуск устанавливает Python 3.12 и PySide6. После установки просмотр работает локально.
Для него не нужны Manim, Cairo, Pango и LaTeX.
На macOS установить uv можно через `brew install uv`.
Для других систем: [инструкция uv](https://docs.astral.sh/uv/getting-started/installation/).
Также доступны `sh run.command` на macOS и `run.bat` на Windows.
На Linux нужен графический рабочий стол. При ошибке Qt/xcb на Ubuntu/Debian:

~~~bash
sudo apt install libegl1 libopengl0 libxcb-cursor0
~~~


## Экспорт MP4

Запускай приложение с дополнительными зависимостями при каждом сеансе экспорта:

~~~bash
uv run --extra export python main.py
~~~

Ярлыки тоже принимают `--extra export`.
На macOS предварительно нужны `brew install cairo pango pkg-config`.
Если потребуются инструменты разработчика: `xcode-select --install`.
На Ubuntu/Debian:

~~~bash
sudo apt install build-essential python3-dev pkg-config libcairo2-dev libpango1.0-dev
~~~

На Windows при ошибке Microsoft Visual C++ установи Microsoft C++ Build Tools
с компонентом Desktop development with C++.

Открой «⋯» → «Экспорт видео…». Можно отключить название, индексы, счётчики и комментарии.
Флаг «Комментарии» управляет пояснениями в видео независимо от настройки просмотра.
Все четыре флага по умолчанию включены.
Для быстрой проверки выбери 480p и короткий ввод.
Экспорт сохраняет всю историю, независимо от позиции просмотра. Скорость просмотра
не меняет темп видео. Задание фиксируется при открытии окна экспорта: после изменения
ввода открой его заново. Повторное одинаковое задание в текущем сеансе использует кеш.

Рендер работает отдельным процессом. Просмотр и меню остаются доступны.
Закрытие окна экспорта скрывает его; «Отменить» останавливает процесс.
При закрытии приложения незавершённый рендер останавливается.
Если этап не сообщает прогресс 45 секунд, в «Подробнее» появляется стек Python.
Это диагностическое сообщение; сам рендер продолжает работать.

## Проверки

~~~bash
uv run python -m unittest discover -s tests -v
uv run python check_environment.py
uv run --extra export python check_environment.py --export
~~~

Без Qt и Manim тесты логики запускаются системным Python:
`python3 -m unittest discover -s tests -v`.
Интеграционные тесты явно пропускаются при отсутствии зависимостей.
Результаты подготовки этой версии записаны в VERIFICATION.txt.

Это исходники прототипа без установщика. Код рассчитан на macOS, Windows и Linux,
но запуск всех платформ здесь не проверен. Python 3.12, PySide6 6.8.3,
необязательный Manim 0.19.0. Первый запуск uv создаёт uv.lock.
